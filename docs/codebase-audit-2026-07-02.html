Themes & patterns5 recurring root causes

T1 — Fake data shown as real The whole app falls back to src/data.js mocks on backend failure with no offline indicator; error and loading state already exist on every hook, but roughly 24 of 25 consumers discard them. Worst offenders: Monitoring OTel (C7) and Heatmap PRNG (C8) fabricate specific, plausible-looking numbers. A single shared offline/stale banner closes most of this.
C7 · C8 · affects ~24 hook consumers
T2 — Blocking I/O on the async event loop The repos, integrations, diffs, agents, user, and files routers all do synchronous filesystem or subprocess work in async def, systemically stalling the WebSocket live feed.
H6 · H7 · H8 · several M/L items
T3 — Silent failures hide data loss Ingest drops files uncounted, the git returncode goes unchecked, and the ingest health log is dead — the dashboard can go quietly wrong with zero signal.
H17 · H18 · C10
T4 — Double-counting running sessions The live-tracker count is added on top of the DB running-count in two places, using the same 60-second window, so the total is nearly always double.
H1
T5 — Singular/plural and type key mismatches from AI generation Graph FILE_SIZES key, useRoute kind maps, OtelEvent.id type, and contract drift are all cross-file key drift that lint cannot catch because it spans JS object shapes rather than syntax.

Methodology

25 review agents scanned the full stack in parallel: frontend components and hooks, backend routers/services/models, CSS and theme consistency across both themes, test coverage, and documentation drift against the actual code. Every finding above was cross-verified against a direct file read at the stated line before inclusion, and duplicate reports from overlapping agents were merged into a single entry.

3 agents (comments, be-jsonl, css-dead) were interrupted mid-synthesis, but their domains were covered by the remaining agents, so no coverage gap resulted. The css-dead agent raw dead-selector list was self-flagged as false-positive-heavy — it could not distinguish genuinely dead selectors from dynamically built classNames (ct-fico-${type}, hljs-*, md-*) — so that raw list is intentionally not reported as findings above.
